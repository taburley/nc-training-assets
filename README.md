# N&C training assets (public)

Images used by Nussbaumer & Clarke tool training videos rendered in Nixie Studio, which fetches each
still by its public URL. One folder per tool and version, e.g. `deed-plot/0.3/s01.png`.

Rules for anything added here:
- Fictional example data only. No client names, addresses, deeds, parcel ids, coordinates of real jobs,
  or anything from a real project. Screens show the tools' built-in fictional examples.
- No keys, tokens, member names or e-mail addresses in any image.
- The script, the exact Nixie brief and the production record live in the private tools repository
  (`nc-tools/videos/<tool>/<version>-<label>/`); this repository holds only the images.
- Tool output shown in these images is a draft for review by a New York licensed professional; it is not
  a survey, a design or advice.
